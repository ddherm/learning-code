# 验证课程与交互

## 内容核验

- 主链每个箭头定位到真实调用；异步事件追注册、绑定或消费边界。
- 承诺完整摘录的符号全部非空行覆盖。片段是否可独立运行，与源码是否原样摘录分别说明。
- 每条解释含条件／输入／状态／返回的因果关系，不能只复述注释。
- 设计推断明确写分析；未测量的性能、调用效果和个人贡献不写成事实。
- 课后题原文和来源逐条核对；默认无答案，题数按用户要求。
- 核心分钟加选读分钟与总时长一致；不要为了压到 3 小时把所有难点搬进必读。

## 静态检查与浏览器检查

生成器先检查源文件路径、行号范围、说明映射、题数、面经原文和完整符号声明。它不证明教学理解正确，也不替代浏览器实际操作。

浏览器脚本需要环境已有 Node、Playwright 和可用浏览器：

```bash
PLAYWRIGHT_MODULE=/已安装的/playwright node <skill>/scripts/check_browser.cjs --html <课程目录>/lesson.html --root <项目目录> --out <临时验证目录> --browser <浏览器可执行文件>
```

`PLAYWRIGHT_MODULE` 可省略，默认 Node 正常模块解析；`--browser` 可省略，使用 Playwright 自带 Chromium。使用现有依赖路径，不把某台机器用户名写死进可复用 skill。环境若要求进程权限，通过正规的权限工具处理，不绕过限制。

检查以下真实行为：

1. DOM 中全部源码行与引用文件切片逐字符一致。
2. 每个按钮范围都在自身卡片里，aria-controls 与真实行 ID 一致。
3. 逐一触发所有按钮，只有目标行高亮；跨卡不残留。
4. 同按钮二次点击取消；Enter／Space 激活；Esc 清除；远处代码自动进入视口。
5. 选读默认折叠，展开后仍可定位；折行与加宽阅读正常。
6. 复制只有原始源码，保留缩进。测试应截取剪贴板 API 数据，不污染用户剪贴板。
7. 测试笔记刷新后恢复，导出内容包含个人回答；在新临时浏览器上下文执行，不触碰用户已有笔记。
8. 桌面 1440px 和手机 390px 均无整页横溢，代码窗自身横向滚动允许。
9. 无 JS 错误，无 HTTP(S) 子资源；源码文件未被验证过程修改。

截图至少人工检查顶部、一个高亮卡片、手机包含长标识的正文／题目。`scrollWidth` 通过不能证明字号、留白、可读性良好。

## 小实验

只在有教学价值时添加，不为普通排版变更编写大量测试。优先固定样例、真实方法和小替身客户端，以检查实际输入／返回／异常。

若从 AST 提取代码，保留函数体、条件、返回值与装饰器；明确替换的依赖，不能修改逻辑后宣称原实现通过。声明跳过的构造器／网络／工具执行范围。源码来自不可信仓库时先审阅，不能把静态读取变成未经审阅的任意代码执行。

记录每个结论的证据：静态分析、替身执行、真实请求或用户实际答题。它们不能互相代替。

## 更新旧课与验证记录

改动前读完整目标文件，保存必要备份。局部替换后比较其他课程与已有回答是否保持原样。个人答案存储键用项目＋课号区分，普通重建不换版本；移动文件和浏览器策略仍需用户导出备份。

验证记录简要列出日期、成品、已过检查、未做检查与修正项。没有浏览器能力时只写静态检查通过，并说明交互尚待验证；不要把脚本存在写成检查已运行。

## 技能自身的检查

`scripts/self_test.py` 使用合成的源码与面经，检查生成成功、原始缩进、映射／引用越界拒绝、完整符号缺行拒绝、题数和答案约束、输出不覆盖输入。可把 fixture 留在临时路径，再运行浏览器脚本。

修改 CSS/JS 后至少复核浏览器交互；只改引用规范时做定向内容审阅即可，不必重新跑完整真实服务或全部业务测试。
