# 按需协作的技能

本技能自身负责源码教学内容、双栏 HTML 和可追溯的代码讲解。
以下技能是按需协作入口，不是运行本技能的安装依赖。
不得为了“配齐工具”而自动安装、复制整包或调用所有技能。

## 调用规则

1. 先判断用户当前任务确实需要什么能力。
2. 在本次会话的可用技能目录中确认该技能和实际路径。
3. 使用前读取它的 `SKILL.md`，再按需读取被引用的文件。
4. 不在可用目录中时，检查合理位置；仍不可用则用现有工具完成相关部分。
5. 技能名称、版本和路径会变化，不把本机用户目录写死为安装前提。
6. 用户明确指定的格式、范围、数量和授权优先于技能默认值。
7. 仅传递任务所需的内容、路径、源码范围与证据，不附无关个人资料。

单纯生成本地教学 HTML 不需要网站发布、在线文档或消息发送能力。
读取技能不等于用户同意上传源码、公开页面、给他人发消息或修改生产服务。

## project-guide：课程主线与仓库理解

**适用**：从仓库安排课程、确认调用链、展开指定课、同步配套练习。

- 使用其源码课程模式和对应的课纲、单课、练习参考。
- 复用真实文件与符号的定位方法、源码优先和局部更新规则。
- 已有教学大纲时沿用用户确认的编号和范围。
- 将输出交给 learning-code 制作双栏、逐项定位和练习交互。
- 不自动进入该技能的完整导学面经模式，也不自动生成简历口播。
- 用户要求完整代码和详细逐行讲解时，以用户要求为准。

**交接内容**：本课目标、源码版本、主链、异常路径、前后课边界。

## interview：用户要求模拟或面试训练时

**适用**：用户明确要求模拟面试、动态追问、掌握度评估或复练。

- 普通课程中的十道无答案练习由 learning-code 完成，不自动开始问答训练。
- 模拟时将本课题目、来源和已讲范围交给 interview。
- 按其契约一次一问，等用户回答后再给证据反馈。
- 默认不在用户回答前给标准答案，不假设用户有未提供的个人经历。
- 是否保存面试表现和复盘，遵守用户意愿及所读技能规则。

**交接内容**：训练范围、题目、已知薄弱点、用户时间与反馈偏好。

## pdf-explore 与 pdf：材料读取与版式

**pdf-explore 适用**：课程依赖 PDF 的多个章节、图表或跨页证据。

- 按其环境支持读取文本、目录和相关页，保留页码与证据位置。
- 文本提取不足以确认图表细节时，查看页面图像。
- 不假设某个 Python 内核或助手函数在所有环境自动存在。

**pdf 适用**：PDF 版式对解读重要，或用户另外要求 PDF 交付。

- 使用其渲染与视觉核验流程。
- PDF 是静态阅读版本，不能宣称仍支持 HTML 点击高亮交互。
- 只要求 HTML 时不顺带导出 PDF。

**交接内容**：所需章节、图表、页码、引用范围或待导出文件。

## agent-browser：页面交互与浏览器验证

**适用**：需要在浏览器检查教学 HTML 的布局、按钮、滚动和键盘交互。

- 先确认本机 CLI 可用；实际执行前读取其版本匹配的使用指南。
- 当前技能入口要求先通过 `agent-browser skills get core` 读取工作流。
- 使用独立测试会话，优先打开本地教学文件；不复用无关登录会话。
- 不可用时，可使用当前环境允许的浏览器工具或已配置自动化运行时。
- 工具选择服从系统和开发者要求，不为 QA 引入全局安装或外部发布。
- 没有实际渲染时，只能报告静态检查通过，不能声称浏览器验证通过。

**交接内容**：文件路径、桌面/窄屏尺寸、点击映射、复制和持久化检查项。

## visualize：对话中的补充解释

**适用**：用户需要在当前对话探索一个机制，交互动画明显有助于理解。

- 可用于演示消息排列、状态变化或参数影响。
- 静态节点与连线足够时使用普通 Mermaid 或简图。
- 一份独立的课程 HTML 不是对话内可视化请求，不因此调用 visualize。
- 需要对话内交互时读取当前完整技能并按其输出契约交付。

**交接内容**：需要解释的单个机制、可调参数和可观察结果。

## documents：用户要求 Word 时

**适用**：用户明确要求 `.docx`、Word 或相应可编辑文档版本。

- 将教学内容转交 documents，并遵守其运行时、模板和渲染核验要求。
- Word 排版与 HTML 不等价，明确静态代码与解读呈现方式。
- 不承诺保留浏览器脚本交互，不自动上传到在线文档服务。

**交接内容**：课程正文、代码范围、版式要求、题目与来源。

## evidence-recap：真实交付过程复盘

**适用**：用户明确要求复盘 AI 编程过程、交付记录、落地状态和证据缺口。

- 仅做源码导学、课程题或模拟面试时不调用。
- 传递真实动作、执行记录、验收结果和职责边界。
- 区分学习实验、原型验证、内部试点与生产落地。
- 不把课程生成或阅读理解升级成用户独立完成了项目交付。

## great-resume：用户要求转成简历表达时

**适用**：用户明确要求把已核实的经历转成简历要点、岗位定位或介绍。

- 先确认实际负责范围，课程学习成果与个人开发经历分开。
- 传递可核验技术动作、结果、证据及待确认事项。
- 不因为课程有面试题就自动改写简历或生成求职消息。
- 起草文案不等于获得发送授权；本技能不自动向外部联系人发送内容。

## 协作完成后的核对

每项交接都应回到用户本次课程目标。
检查协作结果没有扩展题目范围、附上禁用的答案或改变既有课程编号。
在最终交付中只说明实际使用且对结果重要的能力与验证结果。
